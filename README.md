# Kubernetes-End-to-End-Application-Deployment-on-Amazon-EKS
Deployed a containerized 2048 application on EKS using Fargate, Kubernetes Deployments, Services and Ingress. Integrated  ALB for external access and configured IAM OIDC/roles for workload permissions. Used Helm, kubectl and eksctl to automate  deployment and management, reducing manual deployment effort by ~60%.
